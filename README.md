# 折声 VoxMute — TXC 组织研究记录

《嚣城 / THE BUSY CITY》角色设定网站。以 TXC 组织一份研究个案记录的形式，滚动翻阅五页档案。

- **对象登记**：涂黑条随滚动擦开；“发声记录”一栏无法调阅
- **发声功能**：声波在受伤处断开，之后只剩一条窄带载波；指针靠近时载波上扬
- **体表检查**：机器视觉扫描全身，未扫描处是边缘检测线框，扫过处显出原画并标注部位
- **观察日志**：逐条打出；载波读数与血糖同步变化——TXC 能力是一笔代谢账
- **影像资料**：半身像由线稿显出原画，点击画面发出一圈载波

贯穿全站的交互：**有人靠近时，载波就会上扬**。访客的指针就是观察者。

全站中英双语。右上角（手机在右下角）有声音开关，配乐由 Web Audio 实时合成，没有音频文件：冷色调持续和声与磁带底噪、跟随载波读数变化的正弦载波音、零星的钟片单音，以及翻页、盖章、声波断开、扫描到部位的音效。声音默认开启，但浏览器不允许自动出声，所以要等访客第一次点击、触摸或按键后才真正开始。

## 启动

```bash
npm install
npm run dev
```

推送到 `main` 后由 GitHub Actions 自动部署到 GitHub Pages。

## 素材

| 文件 | 用途 |
| --- | --- |
| `public/voxmute.webp` | 全身图（2048×2048，透明背景），用于体表检查页 |
| `public/voxmute-card.webp` | 半身像（2048×2048，透明背景），用于影像资料页 |

替换图片后，体表检查页各部位标注的位置在 `src/main.ts` 的 `PARTS` 里按图片的相对坐标调整。线框由浏览器实时做边缘检测生成，无需另外准备。

## 文字

档案文字分别在 `index.html`（第 1、2、5 页）和 `src/main.ts`（部位说明 `PARTS`、观察日志 `LOG`），每条都有中英两个版本。配乐在 `src/sound.ts`。尚未确定的设定以涂黑或“待查”处理，不预先补答案。
